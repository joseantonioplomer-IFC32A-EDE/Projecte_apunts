Metadatos en HTML

¿Qué son los metadatos?

Son información que se coloca en el documento para describir sus características (autor, descripción, palabras clave, instrucciones para buscadores...). Se escriben dentro de head y no se muestran en la página, pero ayudan a navegadores, buscadores y aplicaciones a entender el contenido.

Charset (juego de caracteres)

Define los caracteres del documento. UTF-8 admite casi todos.

meta charset="UTF-8"

Viewport (diseño responsive)

Hace que la página se adapte bien a distintos tamaños de pantalla, sobre todo en móviles.

meta name="viewport" content="width=device-width, initial-scale=1.0"

Descripción de la página

Breve descripción que usan los buscadores en los resultados.

meta name="description" content="Este es un sitio web que ofrece información sobre HTML5."

Palabras clave (keywords)

Conjunto de palabras que describen la página. Hoy los buscadores las usan poco.

meta name="keywords" content="HTML5, desarrollo web, CSS, JavaScript"

Autor

meta name="author" content="Nombre del autor"

Instrucciones para robots de búsqueda

Indican a los buscadores cómo indexar y rastrear la página.

meta name="robots" content="index, follow"

Open Graph (redes sociales)

Permiten que las redes sociales muestren una vista previa personalizada al compartir un enlace.

meta property="og:title" content="Título de la página" meta property="og:description" content="Descripción de la página" meta property="og:image" content="imagen.jpg" meta property="og:url" content="https://www.ejemplo.com"

Aplicaciones móviles y favicon

link rel="apple-touch-icon" href="icon.png" link rel="icon" href="favicon.ico" type="image/x-icon"

El favicon no es un meta, pero es un metadato visual: el icono de la pestaña del navegador. apple-touch-icon es el icono al guardar la página en la pantalla de inicio de un móvil.

Atributo lang

Se pone en html para indicar el idioma de la página (o en otra etiqueta para marcar un idioma concreto dentro del contenido).

html lang="es" ... /html

Buenas prácticas

  • Usar UTF-8 para que todos los caracteres especiales se vean bien.
  • Incluir una descripción relevante de la página.
  • Usar viewport para optimizar la página para móviles.
  • Incluir Open Graph si se quiere una vista previa atractiva en redes sociales.
  • Usar la etiqueta robots para controlar la indexación.
