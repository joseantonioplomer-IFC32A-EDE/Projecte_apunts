Otras etiquetas: center, div, span, hr, template e iframe

En el índice del PDF este punto aparece como "Etiqueta". Agrupa las etiquetas que se explican en las diapositivas 22 a 27.

1. Etiqueta center (obsoleta)

Se usaba en versiones antiguas de HTML para centrar contenido. Está obsoleta en HTML5 y no se debe usar. Hoy se centra con CSS.

Bienvenidos a mi sitio web

2. Etiqueta div

div (division) crea contenedores de bloque: ocupa todo el ancho disponible y empieza en una línea nueva. No tiene significado semántico; solo agrupa elementos y suele estilizarse con CSS.

Sección 1

Este es un párrafo dentro de un div.

Buena práctica: no abusar de div cuando existan etiquetas semánticas más adecuadas header, section, article ,footer.

3. Etiqueta span

span es una etiqueta en línea (inline): ocupa solo el espacio necesario. Tampoco es semántica; se usa para dar estilo a una parte pequeña de un texto.

Este es un span.

4. Etiqueta hr

hr dibuja una línea horizontal. En HTML5 tiene valor semántico: indica un cambio de tema dentro del documento. No hay que abusar de ella.

5. Etiqueta template

template define fragmentos de HTML reutilizables que no se muestran al cargar la página. Su contenido no se añade al documento hasta que se usa con JavaScript (clonándolo e insertándolo), por eso se usa en aplicaciones dinámicas.

6. Etiqueta iframe

iframe (inline frame) permite insertar una página dentro de otra: vídeos de YouTube, mapas de Google Maps, formularios externos, etc. Atributos habituales: width, height, src, allowfullscreen y sandbox (limita lo que puede hacer el contenido incrustado, para mayor seguridad).

Buenas prácticas: no abusar de los iframes (ralentizan la página), usar sandbox por seguridad, ajustar su tamaño a todas las pantallas y permitir pantalla completa en los vídeos.
