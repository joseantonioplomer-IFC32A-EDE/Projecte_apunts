Introducción a HTML

¿Qué es HTML?

  1. HTML (HyperText Markup Language) es el lenguaje de marcas que se usa para crear páginas web.
  2. Define la estructura de la página mediante etiquetas que el navegador interpreta para mostrar el contenido.

Breve historia

  1. Fue creado por Tim Berners-Lee en 1991.
  2. HTML 2.0 (1995): primer estándar oficial.
  3. HTML5 (2014): última versión, con novedades como soporte para vídeo, audio y gráficos.
