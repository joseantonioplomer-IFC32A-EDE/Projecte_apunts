Estructura básica de un documento HTML

Estructura general

Un documento HTML tiene una estructura jerárquica de etiquetas que definen las distintas partes de la página.

Todas las páginas siguen una estructura parecida: empiezan con!DOCTYPE&y después van las etiquetas html head y body

Ejemplo

!doctype html html head /head body /body /html

Qué hace cada parte

  • !DOCTYPE html: indica al navegador que el documento es HTML5.
  • html: contiene toda la página.
  • head: información de la página que no se ve directamente (por ejemplo el título).
  • body: el contenido visible (textos, imágenes, enlaces...).
