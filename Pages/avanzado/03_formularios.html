Formularios con HTML

La etiqueta form

Los formularios permiten al usuario enviar datos a un servidor. Se crean con form, que es el contenedor de todos los campos. Al enviarlo, cada campo viaja como dato al servidor.

action indica a dónde se envían los datos y method cómo se envían (GET o POST).

Campos de texto: input

input es el elemento más versátil. El tipo de campo se define con el atributo type.

Etiquetas de campo: label

label etiqueta un campo y mejora la accesibilidad. El atributo for debe coincidir con el id del campo.

Texto largo: textarea

textarea name="comentario" rows="4" cols="50" placeholder="Escribe tu comentario aquí"/textarea

Listas desplegables: select y option

label for="ciudad"Selecciona tu ciudad:/label
select id="ciudad" name="ciudad"
 option value="barcelona" Barcelona/option
 option value="madrid" Madrid/option
 option value="valencia" Valencia/option
/select

 
Con el atributo multiple se pueden seleccionar varias opciones:
 select name="intereses" multiple
 option value="programacion"Programación/option
 option value="diseno"Diseño/option
 option value="marketing"Marketing/option
/select
