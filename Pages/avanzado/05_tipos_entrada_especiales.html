Tipos de entrada especiales

¿Para qué sirven?

Estos tipos de input validan y muestran los campos de la forma más adecuada según el dato que se espera del usuario (correo, número, fecha, color...).

Lista de tipos

  • password: oculta lo que se escribe.
  • email: comprueba que tenga formato de correo.
  • url: comprueba que sea una dirección web.
  • tel
  • number: número (con min, max y step).
  • range: barra deslizante.
  • date: fecha.
  • time: hora.
  • datetime-local: fecha y hora.
  • month: mes.
  • week: semana del año.
  • color: selector de color.
  • file: para subir un archivo.
