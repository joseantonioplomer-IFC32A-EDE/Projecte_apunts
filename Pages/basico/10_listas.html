Listas en HTML

Listas no ordenadas (ul)

Se usan cuando el orden de los elementos no importa. Se muestran con viñetas. Cada elemento se define con <li> (list item).

Listas ordenadas (ol)

Se usan cuando el orden sí es importante. Se numeran automáticamente (1, 2, 3...) y cada elemento también usa <li>.

Atributos de las listas ordenadas

Atributo type

Define el tipo de numeración: 1 números (por defecto), A mayúsculas, a minúsculas, I romanos en mayúsculas, i romanos en minúsculas.

  1. Primer ítem
  2. Segundo ítem

Atributo start

Define el número o letra por el que empieza la numeración.

  1. Ítem número 5
  2. Ítem número 6

Buenas prácticas

  • Usar <ul> cuando el orden no importe y <ol> cuando sí.
  • Personalizar las listas con los atributos adecuados según las necesidades.
